## Native and unsafe boundaries

Servo font configuration is target dependent: `components/fonts/Cargo.toml:21` limits FreeType bundling to Linux/Android/OHOS and `:98` uses dwrote on Windows. HarfBuzz is optional and its Windows branch uses DirectWrite. Do not report every workspace-lockfile package as present in a Windows artifact. Mandatory mozjs is the decisive Rust-boundary violation for unchanged Servo; actual selected-build native inventories remain necessary.

html5ever is Rust but has unsafe SIMD/data-state routines (`html5ever/src/tokenizer/mod.rs:2916`, x86 SSE2/ARM paths) and unchecked tendril slicing (`markup5ever/util/buffer_queue.rs:145`). Our crate's `forbid(unsafe_code)` does not cover these dependencies. Required focused review: prove scanned byte index is within live tendril length and at a UTF-8 boundary before slicing; SIMD reads require enough initialized input and appropriate CPU support. Source search is not proof of absence of other unsafe/native dependencies. Root must inspect the exact registry sources and selected Windows dependency graph.

## First slice contract

`Document::parse(&str) -> Result<Document, Error>` accepts at most 256 KiB UTF-8, bounded 32,768-node flat arena. `Document::layout(width) -> Result<DisplayList, Error>` accepts width 64..8192, returns deterministic document-coordinate text runs with estimated advances, bounded height/run count. The Windows caller draws/clips/scrolls these with documented OS interfaces. No network, script execution, CSS, form interaction or sandbox claim. Head/script/style/template content is not rendered; unsupported required capabilities remain diagnostic and in parity backlog.

TreeSink cannot directly return allocation errors. The implementation must stop incremental parser input when the sink records node overflow; overflow handles preserve unique identity/name without inserting arena nodes. Mutation and traversal use integer links with no recursive ownership/drop. Tests must verify malformed/adoption/foster cases, Unicode/entities, node/input/viewport limits, deep nesting and display bounds. This is a static document milestone, not browser completion.

## Critical path and specific blockers

1. Bounded parser/DOM/display-list slice and independent dependency/unsafe review.
2. Renderer process, AppContainer and validated bounded IPC before remote hostile content. A local-only demo cannot establish sandboxing.
3. Audited TLS/HTTP/origin policy and Windows certificate integration; production RustCrypto provider currently warned against by upstream.
4. Complete mutable DOM/WebIDL/JS event loop, JS engine resource interruption, worker isolation and Test262 reporting. Boa's source current MSRV is beyond host; released compatible version differs.
5. CSS cascade, selectors, all layout modes, text shaping, compositing, painting and WPT. Small parser or rasterizer does not supply these.
6. Wasm proposal gaps/JS integration, media codec/DRM availability, graphics/RTC/WebGPU, storage/service workers, extensions and sync. These remain required work; no substituted engine.
