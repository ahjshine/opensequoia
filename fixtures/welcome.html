OpenSequoia

A Rust browser app in development.

Open a local document

Press Ctrl+L and enter a trusted local HTML filename. Open about:guide for keyboard shortcuts, or use the Guide button.

Use tabs, Back, Forward and Reload to explore local pages. Their text is parsed and laid out by the Rust renderer in a separate child process.

Entities decode here: trees & sunlight. Unicode stays intact: Sequoia — नमस्ते — 日本語.

Keyboard interaction

Ctrl+T opens a tab, Ctrl+W closes it, and Ctrl+Tab switches tabs. Click the page to scroll with arrows, Page Up, Page Down, Home and End. Resize the window to reflow text.

Implementation status

The current app supports local text, headings, paragraphs, divisions and line breaks. Remote browsing, CSS, scripts, links, forms, images, profiles and most modern web APIs are still being implemented.

Use trusted development files. Full compatibility, privacy, isolation, extensions and performance gates must be verified before release.

Security gates

No remote browsing is enabled before process isolation, Windows sandboxing, origin policy and certificate verification exist.
