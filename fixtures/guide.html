Browse with OpenSequoia

This development app opens built-in pages and trusted local HTML files with its Rust engine.

Navigate

Press Ctrl+L to focus the address bar. Type about:welcome, about:guide, or a local HTML filename, then press Enter.

Use Back and Forward, or Alt+Left and Alt+Right, to move through a tab's history. Reload with F5.

Tabs

Ctrl+T opens a tab. Ctrl+W closes the current tab. Ctrl+Tab and Ctrl+Shift+Tab select another tab.

Read

Scroll with the mouse wheel, arrow keys, Page Up and Page Down. Home and End move to the top and bottom.

Development limits

Remote browsing remains disabled. HTML text and headings render; CSS, JavaScript, media, full page accessibility and most modern browser APIs are still being implemented.

Use trusted local fixtures. Process containment is an incremental security control; production sandboxing and origin permissions remain required work.
